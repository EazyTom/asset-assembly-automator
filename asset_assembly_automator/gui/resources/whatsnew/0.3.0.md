# What's New in v0.3.0

## Meshy

- Quality preset uses **meshy-7.1**. Game-ready uses **meshy-t2.5** (up to 30k polys).
- **Geometry detail** (`standard` / `2k` / `4k`) replaces Ultra mode. Existing `ultra_mode: true` still maps to 2k.
- Create calls are no longer retried in a way that can charge twice. Polling waits up to 60 minutes and reattaches to the same task.
- Failed tasks record Meshy's error. Transient failures are refunded and created once more.
- Credits stored on each job come from Meshy's `consumed_credits`.

## Mesh review

- Optional pause after image-to-3D, in the Command Center **Mesh Review** tab and in the workflow window.
- **Retexture** makes a new texture on the same mesh (about 10 credits, 15 at 8K). Approve a variant and remesh, rig, and export use it.
- CLI: `aaa retexture`, `aaa mesh-variants`, `aaa approve-mesh`.

## Other

- Default idles (Idle 3, 4, 12) resolve from Meshy's animation library again.
- The Animations tab browses that library. It does not change a pipeline's clips.
- The Phase 2 tab lists world stages only. Unity import already runs from the workflow window.
- Python package `mcp` stays on 1.x so Higgsfield sign-in keeps working. Do not upgrade it to 2.x yet.
