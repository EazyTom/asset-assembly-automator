# What's New in v0.2.0



## Added



- **Asset kinds:** Character, Vehicle, Aircraft with branched stage graphs

- **Meshy dual presets:** Quality (meshy-7, 8K PBR) vs Game-ready (smart-topology)

- **Magnific auto-uprez** stage after concept approval

- **Deterministic Unity import** via `com.assetassembly.import` UPM package

- **Tools → Logs / Show errors / Diagnostics**

- Structured logging with `duration_ms` and parallel Meshy/Magnific + Unity wait-queue

- Agent repair (Cursor or Claude CLI) only when C# validation fails



## Required dependencies



| Dependency | When | Notes |

|------------|------|-------|

| **Meshy API key** | Meshy stages (i2d → export) | Only external API required for FBX output |

| **Unity 6 Editor** | `unity_import` (`s11`) | Target project open while import runs; URP/HDRP/Built-in supported by package |

| **Unity MCP** (one bridge) | Repair, cleanup, Diagnostics ping | Default **AnkleBreaker** `unity` / **user-unity**; Coplay + Official fallbacks in Settings |

### Unity MCP — default AnkleBreaker, fallbacks supported

| Priority | Bridge | Cursor server id | Use with AAA |
|----------|--------|------------------|--------------|
| **1 — Default** | [AnkleBreaker](https://github.com/naniknataraj/unity-mcp-server) | `unity` → **user-unity** | Repair, cleanup, Diagnostics (`unity_*` tools) |
| **2 — Fallback** | [Coplay Unity MCP](https://github.com/CoplayDev/unity-mcp) | **user-unityMCP** | `execute_code`, `read_console`, … |
| **3 — Fallback** | [Official Unity MCP](https://docs.unity3d.com/Packages/com.unity.ai.assistant@2.0/manual/unity-mcp-overview.html) | **user-unity-mcp** | `Unity_*` tools |

Configure in Cursor **MCP settings** or repo [`mcp.json.example`](../../../../mcp.json.example) (copy to `.mcp.json` — gitignored). Pick bridge in **Settings → Unity MCP bridge**. **Unity Editor must be open** on the project set in AAA.



Also required for agent repair: **Cursor CLI** (`cursor-agent` on PATH) or **Claude CLI** (Settings → Agent for Unity repair).



## Changed



- Remesh is optional and **off by default**

- Image prep cap raised to 4096px for Magnific-friendly Quality runs

- Unity helpers moved from loose `Assets/` copies to injected UPM package

- **Concept providers clarified:** only Meshy is required for 3D; Higgsfield, Magnific, and Midjourney are optional ways to supply the approved reference image
