# What's New in v0.4.0

## Meshy API v2

- The app can talk to Meshy API v2. The default stays **v1** until you set `meshy.api_version: v2` (or `AAA_MESHY__API_VERSION=v2`).
- v2 sends an explicit texture model (`meshy-7`) with pinned geometry (`meshy-7.1` or `meshy-t2.5`) and always asks for FBX and GLB.
- Retexture on v2 uses `texture_prompt` / `texture_image_url` and `uv_mode`.
- Task results are read from `output`. Status checks use one route, `GET /openapi/v2/tasks/{id}`.

## Pipeline waits

- On v2, status waits follow Meshy's task stream and fall back to polling.
- Cancel while a v2 task is still `PENDING` asks Meshy to delete it so the charge can be refunded.
- Texture maps download together, up to four at a time.
- Idle 3, Idle 4, and Idle 12 run at the same time, up to `meshy.max_concurrent_jobs`.
