# Getting Started — Asset Assembly Automator

Welcome! Configure these services before running character pipelines.

## Required

1. **Meshy API key** — [Get key](https://www.meshy.ai/settings/api)
2. **Higgsfield MCP** — Install the Higgsfield plugin in Cursor and authenticate

## Optional (Phase 2)

3. **Unity MCP** — [Unity MCP docs](https://docs.unity3d.com/Packages/com.unity.ai.assistant%402.0/manual/unity-mcp-overview.html)
4. **Blender MCP + Auto-Rig Pro** — [blender-mcp](https://github.com/ahujasid/blender-mcp)

## Midjourney (manual)

Midjourney has no official API. Copy prompts from the Prompt Builder, generate in MJ, then drop images into the watch folder or import manually.
